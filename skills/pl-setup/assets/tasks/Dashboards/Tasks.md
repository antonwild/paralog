# Tasks

All open tasks in the vault (Tasks plugin, global filter `#task`). Tasks live in the daily notes; tick them here or there.

> [!danger] Overdue
> ```tasks
> not done
> (due before today) OR (scheduled before today)
> sort by due
> hide toolbar
> ```

> [!todo] Today
> ```tasks
> not done
> (due today) OR (scheduled today)
> sort by priority
> hide toolbar
> ```

> [!info] Upcoming
> ```tasks
> not done
> (due after today) OR (scheduled after today)
> sort by due
> hide toolbar
> ```

> [!question] For my manager
> ```tasks
> not done
> tags include #for-manager
> sort by due
> hide toolbar
> ```

> [!note] No date
> ```tasks
> not done
> no due date
> no scheduled date
> group by tags
> sort by priority
> hide tags
> hide toolbar
> ```

> [!success]- Done in the last 7 days
> ```tasks
> done after 7 days ago
> sort by done reverse
> hide toolbar
> ```
